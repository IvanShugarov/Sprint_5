# Автоматизация тестирования учебного стенда QA-Desk

Проект по автоматизации ключевых пользовательских сценариев для платформы объявлений.

## Реализованные проверки
Тесты разделены по функциональным блокам (классам) и включают в себя:
* **Регистрация пользователя**: позитивные и негативные сценарии, проверка уникальности email.
* **Авторизация (Login/Logout)**: вход в систему и корректное завершение сессии.
* **Создание объявления**: проверка логина перед публикацией и полный цикл создания товара.

## Стек технологий
* **Python 3**
* **Pytest** (тестовый фреймворк)
* **Selenium WebDriver** (автоматизация браузера)
* **WebDriver Manager** (управление драйверами)

## Структура проекта
* `tests/` — папка с тестовыми модулями (классы тестов по функциональностям).
* `conftest.py` — общие фикстуры (инициализация драйвера, авторизация пользователя).
* `locators.py` — все локаторы элементов (Page Object Pattern).
* `helpers.py` — вспомогательные функции (генератор случайных данных).
* `requirements.txt` — список необходимых библиотек.
* `.gitignore` — исключение системных файлов из репозитория.

## Инструкция по запуску
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите все тесты:
   ```bash
   pytest
   ```
